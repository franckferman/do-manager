A modular Go CLI and library for managing DigitalOcean infrastructure. Provision, inspect, and destroy Droplets programmatically or from the terminal.

Go 1.21+ AGPL-3.0 godo v2 API v0.1.0
Get Started View on GitHub

Overview

do-manager is built on top of godo, the official DigitalOcean Go client. It is designed as a dual-purpose project:

🖥

CLI Tool

Manage your DigitalOcean account from the terminal with colored, tabular output and interactive prompts.

📦

Go Library

Import pkg/droplet, pkg/sshkey, or pkg/region directly in any Go project.

⚡

Parallel Ops

Provision or destroy N Droplets simultaneously via goroutines with panic recovery and per-op error reporting.

🔧

No doctl needed

Direct API calls via godo. No external binary, no subprocess parsing, no version mismatch.

Installation

Requires Go 1.21+.

From source

bash
$ git clone https://github.com/franckferman/do-manager.git $ cd do-manager $ go mod tidy $ go build -o do-manager . $ ./do-manager version do-manager v0.1.0

go install

bash
$ go install github.com/franckferman/do-manager@latest

Configuration

The API token is resolved in this order (first match wins):

MethodExample
--token flagdo-manager --token dop_v1_xxx droplet list
DO_TOKEN env varexport DO_TOKEN=dop_v1_xxx
~/.do-manager.yamltoken: dop_v1_xxx
Generate a Personal Access Token at cloud.digitalocean.com/account/api/tokens. Read+Write scope required for all write operations.

Config file

Droplets

Full lifecycle management: list, inspect, provision (single or batch), delete, and power control.

List

do-manager droplet list

[y/N]: y ✓ Droplet 123456789 deleted. $ do-manager droplet delete 111 222 333 444 555 ✓ ID=111 deleted ✓ ID=222 deleted ✓ ID=333 deleted ✓ ID=444 deleted ✓ ID=555 deleted $ do-manager droplet delete --tag lab --force ✓ All Droplets with tag lab deleted.

SSH Keys

ssh-key commands
# List all keys $ do-manager ssh-key list # Add from a file $ do-manager ssh-key add --name homelab --file ~/.ssh/id_ed25519.pub ✓ SSH key added ID=42000001 Fingerprint=xx:xx:xx:... # Add inline $ do-manager ssh-key add --name ci --public-key "ssh-ed25519 AAAA..." # Inspect $ do-manager ssh-key get xx:xx:xx:... # Delete $ do-manager ssh-key delete xx:xx:xx:...

Regions, Sizes & Images

resource discovery
# All regions with availability $ do-manager region list # All size slugs with specs and pricing $ do-manager size list # Distribution images (default) $ do-manager image list # Application images $ do-manager image list --type application # All images $ do-manager image list --type ""

Library Usage

The pkg/ packages are designed to be imported independently of the CLI. Each package is stateless and accepts a context.Context for deadline and cancellation propagation.

Go
import ( "context" "os" "github.com/franckferman/do-manager/pkg/client" "github.com/franckferman/do-manager/pkg/droplet" "github.com/franckferman/do-manager/pkg/sshkey" "github.com/franckferman/do-manager/pkg/region" ) func main() { // Authenticated client c, err := client.New(os.Getenv("DO_TOKEN")) ctx := context.Background() // -- Droplets -- svc := droplet.New(c) list, _ := svc.List(ctx) d, _ := svc.Get(ctx, 123456789) _, _ = svc.Create(ctx, droplet.CreateOptions{ Name: "worker-01", Region: "fra1", Size: "s-1vcpu-1gb", Image: "ubuntu-22-04-x64", }) // Batch: 5 Droplets in parallel results := svc.CreateBatch(ctx, opts, 5) // Destroy in parallel errs := svc.DeleteMany(ctx, []int{111, 222, 333}) // Destroy by tag (single API call) svc.DeleteByTag(ctx, "lab") // -- SSH Keys -- keySvc := sshkey.New(c) keys, _ := keySvc.List(ctx) // -- Resources -- regSvc := region.New(c) regions, _ := regSvc.ListRegions(ctx) sizes, _ := regSvc.ListSizes(ctx) images, _ := regSvc.ListImages(ctx, "distribution") }
The pkg/ packages have no dependency on Cobra, Viper, or any other CLI framework. They only require godo and the standard library.
